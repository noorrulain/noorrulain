<h2>Cool Stuff I've Worked On</h2>
<h3>🩺 <a href="https://github.com/DanialMaqbool/ai600-project">Diabetic Retinopathy Grading using Knowledge Distillation</a></h3>
<p>
Developed a deep learning pipeline for automated five-class diabetic retinopathy grading from retinal fundus photographs.
The system uses an <b>EfficientNet-B4 teacher</b> to transfer knowledge to a lightweight
<b>EfficientNet-B0 student</b>, combining knowledge distillation, ordinal learning and
multi-scale CBAM attention.
</p>
<p>
GradCAM++ was also used to analyze model attention and examine whether predictions were
being driven by clinically meaningful retinal regions.
</p>
<p>
<b>Tech:</b> Python • Deep Learning • Computer Vision • EfficientNet • Knowledge Distillation • CBAM • GradCAM++
</p>

<h3>🎵 <a href="https://github.com/noorrulain/melodymatch">MelodyMatch — Spotify Song Recommender</a></h3>
<p>
Developed a Spotify recommendation system and end-to-end data pipeline that combines
user listening history with Spotify track audio features to discover similar music.
</p>
<p>
The recommendation system uses <b>KMeans clustering</b> to group songs by their overall
vibe and <b>K-Nearest Neighbors with cosine similarity</b> to generate content-based
song recommendations.
</p>
<p>
The surrounding data pipeline handles ingestion, cleaning, validation, storage and serving
using PostgreSQL, Great Expectations, Prefect, Docker and Streamlit.
My primary contribution to the project was <b>Machine Learning and Analytics</b>.
</p>
<p>
<b>Tech:</b> Python • Machine Learning • KMeans • KNN • Pandas • PostgreSQL • Prefect • Docker • Streamlit
</p>
